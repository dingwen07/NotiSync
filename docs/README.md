## Use NotiSync

- [Getting started](getting-started.md): install, grant permissions, pair with QR codes or NFC, and select apps.
- [Desktop tools](desktop.md): install the CLI and daemon, use Run, and manage agent skills.
- [NotiSync Seal](seal.md): approve OpenPGP-signed Git commits and tags on Android.
- [SSH Agent](ssh-agent.md): use phone key providers with SSH clients on Linux, macOS, Windows, and WSL.
- [Screen sharing](screen-sharing.md): connect to a trusted Android screen.
- [Troubleshooting](troubleshooting.md): diagnose delivery, pairing, and desktop problems.

## Host or develop

- [Self-hosting](self-hosting.md): run the broker and configure authentication and push delivery.
- [Development](development.md): build from a fresh checkout, run tests, and contribute.
- [Architecture](architecture.md): understand the modules and delivery flow.
- [Security model](security.md): understand encryption, trust, key storage, and metadata.
